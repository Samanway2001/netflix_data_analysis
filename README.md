# Netflix Data Analysis (Python, Pandas & NumPy)

## Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on the Netflix dataset to understand content production trends, media distributions, target audience ratings, and international market penetration.

## Project Deliverables
* **Google Colab Notebook:** `netflix_data_analysis.ipynb`
* **Raw Dataset:** `netflix_titles.csv`

## Tech Stack & Libraries
* **Platform:** Google Colab
* **Language:** Python
* **Pandas:** Data cleaning, handling missing records, and date parsing
* **NumPy:** Array operations and conditional calculations
* **Matplotlib & Seaborn:** Distribution charts, trend analysis, and heatmaps

## Key Analysis & Insights
* **Content Distribution:** Identified platform split between Movies (~70%) and TV Shows (~30%).
* **Growth Trends:** Tracked yearly content addition spikes and platform catalog scaling.
* **Demographics & Ratings:** Assessed maturity ratings, highlighting dominance in TV-MA and TV-14 content.
* **Regional Insights:** Analyzed top contributor markets and rapid catalog expansion across Asian regions.
